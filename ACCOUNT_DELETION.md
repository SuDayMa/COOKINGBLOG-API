# Account Deletion Policy


## How to Delete Your Account


Users can delete their account directly inside the application by following these steps:


1. Log in to the app.
2. Go to Profile.
3. Open Settings.
4. Tap on "Delete Account".
5. Confirm the deletion request.


## What Data Will Be Deleted


When a user deletes their account:


- All personal information (name, email, profile data) will be permanently deleted.
- All posts created by the user will be deleted.
- All comments created by the user will be deleted.
- Any uploaded images associated with the account will be removed.


## Data Retention


- Account data is permanently deleted from our system within 7 days.
- No personal data is retained after deletion.
- We do not keep backup copies of deleted user data.
